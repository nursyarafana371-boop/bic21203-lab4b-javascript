BIC21203 Web Development — Lab 4b (JSON and jQuery)

This repository contains the files for Lab #4b: Client-Side Scripting (JSON and jQuery).



List of Files



i. books.json
File in json format that is containing record of books.



ii. books.html
File that implement JavaScript, fetch() with createElement() with textContent to display record of books from books.json file.



iii. jquery-dom.html
File that demonstrates Document Object Model (DOM) Manipulation and event handling using jQuery 4.0.0 Content Delivery Network (CDN).



Setup Instructions

1. Clone or download this repository and open the folder in VS Code.
2. Install the Live Server extension in VS Code (if not already installed).
3. Right-click books.html and select Open with Live Server (do not open directly via file://, as browsers block fetch() requests for local JSON files).
4. Open jquery-dom.html via Live Server or directly in a modern browser and click the Click me button to test the alert.
